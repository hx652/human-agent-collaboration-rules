## 项目用途

生成考虑共享空间协调的多机械臂运动规划问题，支持测试和发现现有方法的不足。每条臂具有有序访问目标，完成后返回初始配置。不同臂的同序号访问不默认同步。

## 输入与输出

- 名义场景 `scene` 与生成规则 `generation` 分开，允许同一场景使用不同规则。
- 公共资源统一管理，包括机械臂配置、URDF、mesh。
- 每条输出为一个 YAML，保存具体场景、目标 frame 定义、机械臂实际初始状态、目标序列及必要任务约定。
- 输出保存实际结果，不依赖重新采样；不保存目标的世界坐标系 pose，需要时由相对变换计算。

数据集的组织与代码目录分开。详细文件字段在代码设计与实例验证过程中继续完善。

## 场景与 frame

机械臂使用独立 URDF，通过独立机械臂配置引用。有关节结构的环境物体使用 URDF、实例位姿和关节值；其他物体使用基本几何体、mesh 或组合。

物体 frame、几何 frame 可以不同，通过局部 pose 相连。长方体中心为原点、尺寸为完整边长；圆柱中心为原点、轴线沿局部 z；mesh 保留资源自身坐标系，不自动居中。

候选访问 frame 通过相对于物体 frame 的 pose 定义，该 pose 已包含访问 offset。保留独立命名任务 frame 及围绕名义访问 pose 采样的能力，不引入几何驱动的目标生成。

辅助 frame 的字段组织未确定，但读写时需保持必要信息与引用关系。

## 位姿扰动

场景物体和目标 frame 均从名义状态重新采样，不在上一条样本上累积。位置、旋转都参考旋转扰动前的名义自身坐标系。

采用列向量约定，名义位姿为 `(p0, R0)`：

```text
p = p0 + R0 * delta_p
R = R0 * Rz(gamma) * Ry(beta) * Rx(alpha)
```

即依次绕名义自身坐标系的固定 x、y、z 轴旋转。旋转采样不改变位置扰动方向。对目标 frame，该名义位姿相对于父 frame；父 frame 的变化经变换链传递。

## 机械臂配置与初始采样

公共机械臂配置独立保存，其具体格式（SRDF、自定义配置或组合）待讨论。

公共配置补充 URDF 的规划使用语义，包含模型引用、根 frame、规划关节及顺序、TCP、有效关节位置限制和公共自碰撞规则。场景保存实例安装，各臂任务保存初始规划状态、访问目标和完成条件。非规划关节也属于机器人状态；首版为简化输入，沿用公共机器人配置中的固定值，不提供逐问题变化或覆盖机制。这修正了此前将固定使用状态放在场景中的方案。通用碰撞裕量不归入机械臂公共配置。详见[问题 1、2 的方案](notes/discussions/2026-09-18-first-input-example.md#追加问题-12-的方案)。

公共配置包含命名关节配置，例如 `folded`。命名配置仅表示关节值，不自动指定用途或默认初始状态。

速度、加速度限制作为公共配置中的可选信息；此决定修正此前暂不考虑的范围，过程见上述笔记。

初始状态在各臂配置空间中按 generation 指定的分布采样。首版采用独立均匀分布和单中心独立高斯分布；高斯中心可以引用公共命名配置，也可以直接给出完整关节值。复用的是中心配置，不引入默认采样分布及覆盖机制。此前讨论的多中心方向暂缓。

分布及其参数属于 generation。位姿扰动先采用位置分量和旋转角参数的独立均匀分布，暂不考虑混合分布、旋转专用分布和完整协方差。未配置的扰动对象、属性或分量保持名义值，父 frame 的变化仍正常传递；此规则不适用于必需的初始关节状态。YAML 表达与边界见[问题 3 的方案](notes/discussions/2026-09-18-first-input-example.md#追加问题-3-的方案)。

## 模型资源接口

生成器接收已展开 URDF 及其所需资源。URDF 中资源路径必须相对于 URDF 所在目录，不使用绝对路径或 `package://`。xacro 展开、ROS 包依赖定位及资源转换由独立准备步骤完成，不成为生成器的运行依赖。当前几何处理以 STL 为基础，DAE 外观资源可保留；格式能力和处理边界见上述笔记。

## 访问目标语义

末端 pose 是必须满足的访问目标；保存的关节配置是辅助 IK 解，规划器可以采用其他满足该 pose 的配置。序列中的辅助配置不能被误解释为固定关节终点。

先采用统一访问容差：位置欧氏距离不超过 **0.001 m**，朝向之间的最小旋转角不超过 **1°（π/180 rad）**。辅助 IK 解应满足相同容差。

目标采样范围与目标容差是两件事。返回初始关节配置采用逐规划关节的误差判据：当前有限转动关节的绝对误差不超过 0.001 rad。这是数值验收容差，不替代最终状态的碰撞检查。

首版不提供访问停留时长参数，不要求最短访问停留时间；允许规划器为协调而等待，不额外规定到达速度。

机械臂完成序列并返回初始配置后停留在那里，继续参与碰撞检测，不另设保持开关。

当前输入实例使用各臂独立的固定有序 frame 列表，不要求同序号访问同步。每个 frame 每个样本生成一次 pose，供所有引用共用；访问之间不隐含直线路径要求。
