# 路径碰撞与协调空间：交互示例

交互式教学页面：[打开 index.html](index.html)。直接用浏览器打开，无需安装依赖或联网加载脚本。维护源文件为 index.html 和 three-robots.js；复制页面时两者需要放在同一目录。

## 标签页一：不同路径，相同障碍

由 agent 按用户请求构造，用两个仅平移、半径为 0.4 的圆盘机器人说明：不同配置路径，在相同进度参数约定下，可以产生完全相同的两两碰撞关系。A₁ 的两条路径上下镜像，A₂ 沿对称轴运动，因此对应中心距离严格相同。

页面支持拖动两个进度滑块或协调空间图面，同时查看机器人备选配置、中心距离和碰撞判断。

依据：[LaValle，Fixed-path coordination，公式 (7.11)–(7.12)](https://lavalle.pl/planning/node325.html)。具体镜像例子由 agent 构造，不是原书实例。

限制：示意的是两台二维平移圆盘机器人，不是一般机械臂；两种 A₁ 位置是互斥的备选，而非两台同时存在的机器人。障碍边界绘制为密集折线近似，交互点的碰撞由解析距离式计算。相同障碍不意味着原路径相同，也不意味着障碍与路径无关。未进行真实机器人实验。

## 标签页二：三机器人碰撞关系与完整协调空间

每个机器人用 5 个离散配置点及相邻点间的直线插值定义一条连续路径。机器人为半径 0.35 的平移圆盘，接触计为碰撞。

页面依次展示路径样本、三张连续两两碰撞区域及其 5 × 5 采样矩阵，最后展示完整的连续协调空间 [0,1]³。每个二维碰撞区域沿剩余机器人进度轴拉伸，三组柱状障碍的并集组成整个障碍区域。

该例三条路径均为直线，可以通过圆盘距离条件解析得到圆或椭圆碰撞边界，再拉伸为三维柱体。可视化用多边形近似光滑边界，不是从稀疏采样矩阵推断连续区域。离散编号 k 与连续进度的关系为 s=(k−1)/4。

交互：

- 切换顶部标签页；支持键盘左右方向键。
- 拖动三个状态序号滑块，联动路径配置、矩阵选中格与立方体内的当前状态。
- 点击矩阵格或选择机器人对，高亮相应柱体及沿剩余维度的一列状态。
- “全部障碍”显示三组柱体的并集；拖动立方体可旋转视角。
- 地址加 #three 可直接打开三机器人标签页。

依据：[LaValle，Fixed-path coordination，图 7.9、公式 (7.11)–(7.12)](https://lavalle.pl/planning/node325.html)。具体路径由 agent 构造；未进行真实机器人实验或协调路线搜索。

开发验证：三张采样矩阵与解析连续碰撞判定一致；生成柱体所用边界点满足距离阈值；已检查标签切换、矩阵选择、第三台机器人变化和窄屏布局。预览图片保存在不进入 Git 的 exports/。
