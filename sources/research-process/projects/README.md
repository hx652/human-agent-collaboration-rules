## 组织约定

每个项目先使用一个 README.md 保存上下文和材料入口。
内容确实增多后再增加子文件。
代码和详细实现记录继续留在各自仓库。
影响研究主线的发现链接到整体状态与过程记录。
仓库 URL 写在项目入口，设备专属路径写入 local-paths.md。
