# 研究起点与工作方式

状态：根据用户已确认的讨论整理。
来源：建立第一版工作流前的讨论。
本记录不是完整的既往研究历史。

## 研究起点

研究方向是考虑时序的多机械臂运动规划，
具体含义有待进一步讨论。
已复现 Stop-N-Go，希望发现其表现不够好的场景，
从而寻找改进方向。
计划参考 MotionBenchMaker 实现简单版数据集生成器，
当前尚未开始实现。

## 工程思路的演变

用户意识到方法实现和测试验证构成完整流程，
因此希望建立统一框架。
随后进一步认识到：可以在保持基本可维护性的前提下
先跑通流程，让真实问题暴露，再复盘和完善框架。

“幻想出的问题永远无法解决。”
这是用户此前最大的阻碍之一，表达了脱离实践反馈、
围绕设想问题反复考虑而难以推进的经历。
这句话保留为个人提醒，不作为普遍定律。

## 工作流目标

以完整研究方向与过程为主线，自然关联多个具体项目。
既支持协作，也保存思考、尝试、理由和变化本身。
不只记录最终结果，也不依赖单个 session 保存长期信息。

Agent 提出具体候选更新，用户审阅、修改并确认后写入。
零散想法可以先收集，不强求形成体系。
先从当前的新阶段体验工作流，旧内容按需逐步迁入。

科研是初始场景，未来可以用于其他长期主题。
跨设备同步是必要能力，第一版为其保留支持但暂不配置。
多 Agent 实现与审查协作留待后续探索。
