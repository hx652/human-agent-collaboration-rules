## 布局与参数依据

世界 z 轴向上，桌面长边沿 y。桌子中心线为 x=0、y=0，靠近机械臂的一侧桌边为 x=-0.60 m。基座均沿世界轴安装，x 正方向朝向桌内。

| 桌面中心高度 / 上表面高度 | 0.70 / 0.72 |
| 两臂基座位置 | (-0.78,-0.45,0.72)、(-0.78,+0.45,0.72) |
| 基座中心至桌边 | 0.18 |
| 两基座中心间距 | 0.90 |
| 独立支座 | 0.18×0.18×0.72，支座顶面与桌面齐平 |
| 支座前缘至桌边空隙 | 0.09 |
| 两圆柱目标中心 | (-0.30,-0.10,0.78)、(-0.30,+0.10,0.78) |
| 圆柱尺寸 | 半径 0.03，高 0.12，底部位于桌面 |
| 两访问 TCP 位置 | (-0.30,-0.10,0.98)、(-0.30,+0.10,0.98) |
| 新增两较高目标位置 | (-0.30,-0.10,1.04)、(-0.30,+0.10,1.04) |

| 球形 mesh 的平面位置 | (0.23,-0.45)；按原始 mesh 最低顶点计算 z，恰好落在桌面 |

保留原桌子的尺寸、桌腿和基本形状表达，将原 table 的 x 坐标整体平移 -1.05 m 以便解释。重新安置 Can1 和 Cube，复制一个圆柱作为第二个候选目标，删去原 Object1–Object5；新增两座支座和球形 mesh。环境在本例中固定，不模拟抓取或物体移动。

两臂处于同一长边，避免隔着 2 m 桌宽相向安装而缺少共享区域。两目标处在桌前的共享区域；基座到目标的水平距离约为 0.594 m（近侧）和 0.730 m（跨侧）。这些距离只用于初步设计，可达性依据下述实际模型 IK 检查。

最初试过更靠后的目标，跨侧访问未找到通过检查的配置；向桌前移动并缩小目标间距后，四个“臂—目标”组合均找到合适配置。未使用渲染图决定布局。

## 机械臂、夹爪与 TCP

UR7e 使用 Universal Robots 官方参数。该参数文件官方引用 UR5e mesh，因此资源中出现 `meshes/ur5e` 是上游设计，并非本项目把 UR7e 偷换为 UR5e。模型采用通用参数，不是某台实物的校准模型。

Robotiq 官方 UR 转接件连接到 UR `tool0`，夹爪经 0.011 m 适配器偏移连接。关闭 ros2_control 部分，仅保留几何与运动学。UR 模型根部增加了同位姿的 `base_mount` 作为实例安装 frame。

夹爪独立关节 `robotiq_85_left_knuckle_joint` 固定为官方参数中的闭合值 **0.7929 rad**，其余活动夹爪关节按官方 mimic 关系推导。关节上限 0.8 rad 不直接当作闭合值。

本例定义 `grasp_tcp`：相对夹爪基座 `(0,0,0.145)`，轴向一致。这是项目的规划参考点，不是厂商标定的抓取中心。它位于闭合指尖中间区域；闭合指尖 mesh 在基座坐标系的 z 范围约为 0.106–0.163 m。访问时 TCP 的 z 轴向下，目标位置在圆柱顶部上方 0.14 m；不要求夹爪接触或夹住圆柱。

## 需要哪些初始配置

基准布局使用完整臂配置和固定的闭合夹爪状态；生成规则另行明确初始分布，不由命名配置自动决定。

- `home`：官方 UR MoveIt SRDF 命名姿态，作为两臂确定性基准初始配置。
- `up`：同一官方文件中的替代参考姿态，用于检查和比较。
- 夹爪闭合值：固定在机器人配置中，不参与本次初始分布采样。

两种臂姿态均含 elbow=0，可能处于奇异或接近奇异配置；其作用是有来源的几何参考，不能宣称是最适合的采样中心。本次分布实例选择 home 附近的状态，不代表已验证该选择适合后续规划。MoveIt 的 `test_configuration` 未作为本例初始配置采用。

## 分布输入实例

`../../../examples/ur7e_table/inputs/tabletop/generation.yaml` 使用种子 42、样本数量 10 展示输入，尚无生成器执行这些规则。数值是示例参数，不是随机可行性验证结果。

| 对象 | 示例分布 |
|---|---|
| 桌子、支座、机械臂基座 | 固定，不填写扰动配置 |
| 方块 | 局部 x/y 均匀扰动 ±0.03 m，gamma ±0.1 rad |
| 两个圆柱 | 局部 x/y 均匀扰动 ±0.02 m，gamma ±0.1 rad |
| 球形 mesh | 局部 x/y 均匀扰动 ±0.03 m，朝向固定 |
| 两个 visit 目标 frame | 各位置分量均匀扰动 ±0.005 m，各旋转参数 ±0.03 rad |
| 两个 above 目标 frame | 无自身扰动，保持相对父圆柱的名义 pose |
| arm_a 初始关节状态 | home 附近的独立均匀分布，明确填写六个关节的实际上下界 |
| arm_b 初始关节状态 | 以命名配置 home 为中心的独立高斯分布，逐关节填写标准差 |

所有位姿均从名义状态重新采样，位置增量参考名义自身坐标系，旋转按 `R0 * Rz(gamma) * Ry(beta) * Rx(alpha)` 组合。目标跟随采样后的父对象，再体现自身的相对扰动；扰动范围与访问容差分开。分布内分量和不同对象分别独立采样，夹爪不参与采样。

未写出的扰动对象、属性或分量保持名义值，父 frame 的变化仍正常传递；这一省略规则不适用于必需的初始关节状态。

高斯分布不隐含截断或裁剪；越界、碰撞和不可达样本如何处理尚未确定。已有 `validation-2026-09-18.json` 仅验证名义场景，不覆盖这些分布。

## 访问序列实例

`sequence_generation.type: fixed` 表示直接采用 `sequences` 中各臂的有序 frame 列表，访问次数由列表长度确定：

- arm_a：`can_a_above → can_a_visit → can_b_above → can_b_visit`。
- arm_b：`can_b_above → can_b_visit → can_a_above → can_a_visit`。

每臂四次访问，无跨臂同步要求。每个 frame 每个样本只生成一次 pose，各臂引用同一 frame 时共享目标定义。above 是独立访问目标，相对圆柱高度为 0.26 m；它不表示抓取动作，也不约束到 visit 的运动必须是直线。两个目标独立定义，visit 自身扰动不会带动 above。

`completion.return_to_initial_configuration: true` 表示完成序列后返回该样本实际初始关节状态，之后停留在那里并继续参与碰撞检测，不另设保持开关。`joint_tolerance_rad: 0.001` 表示本例每个规划关节返回时的绝对误差不超过 0.001 rad。首版不提供 `dwell_time_s`，不要求最短访问停留时间，不禁止协调等待，也不额外约束到达速度。

## 数值检查及其范围

2026-09-18 的原始检查读取实际 YAML 和组合 URDF，使用 SciPy 数值 IK、python-fcl 三角网格碰撞查询，无额外膨胀：

- 两臂各自 `home`、`up` 没有检测到禁止的自身或环境碰撞。
- 两臂同时处于 `home` 时未检测到臂间碰撞。
- 两臂分别访问两个候选目标的四种组合均找到满足 1 mm / 1° 容差的配置，且另一臂保持 `home` 时没有检测到臂间碰撞。

2026-09-21 新增 above 目标后，已核对两条臂到两个新目标的四组名义 IK 均满足同一容差和关节限位，并验证预览数据可加载四个 frame。当前环境缺少 `python-fcl`，未重新执行碰撞检查。`baseline.yaml` 已将四个目标全部列入后续检查；旧 `validation-2026-09-18.json` 保留为原始结果，输入哈希已不匹配当前场景，预览不会继续加载其中的 IK 见证。

排除规则：上游 UR SRDF 的自碰撞对；固定/锁定为同一刚性组件的内部几何对；每条臂底座与自身支座的预期安装接触。闭合夹爪被当作固定组件，不在本检查中验证夹爪内部机械接触设计。

**未检查：** 连续运动路径、访问顺序可规划性、双臂同时运动的调度、任何随机扰动后的可行性。找到 IK 和无碰撞端点不构成路径存在证明。`validation-2026-09-18.json` 中的关节值是检查见证，不是规划终点约束或生成的正式样本。

检查脚本是用于本例的数值原型，不决定生成器的语言或后端。依赖版本记录在 JSON 中；需要 numpy、scipy、PyYAML 和 python-fcl。依赖可用时从仓库根目录运行：

```bash
python3 tools/baseline_validation/ur7e_table/check_baseline.py
```

URDF 已展开，普通消费者不需要 xacro。若要重新生成，需要 xacro 与 ament_index_python：

```bash
python3 tools/model_preparation/ur7e_2f85/build_model.py
```
