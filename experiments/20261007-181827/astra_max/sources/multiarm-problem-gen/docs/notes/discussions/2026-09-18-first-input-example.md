## “最小但完整”的含义

用尽量少的对象和机制覆盖必要的输入内容，不仅选择最容易的几何场景。基本几何体和 mesh 在资源引用、缩放和局部位姿处理上有所不同，因此 mesh 是这份样例的明确组成部分，不作为可省略的装饰。

最终应能看清机器人模型与实例、环境对象、访问 frame、初始配置分布、访问序列和生成规则之间的关系。格式中尚未确定的部分，在构造样例时提出具体候选并讨论，不静默采用默认值或把候选字段当成定稿。

agent 建议不以“完整”为由一次塞入所有可选能力，例如有关节的环境物体；该建议用于控制范围，具体功能覆盖边界仍可随样例讨论调整。

1. URDF 中 link 与 joint 构成的运动学结构。
2. xacro 的 include、宏和 YAML 参数等源文件组织，展开后生成 URDF。
3. URDF 对 mesh 的引用，以及部分 mesh 对材质、纹理等文件的依赖。

mesh 的关系取决于具体格式：STL 通常为独立三角面数据；OBJ 可以包含分组并引用材质、纹理；DAE、glTF 可以包含节点层次、局部变换和资源引用。这些不等同于机器人关节结构。

后续应讨论模型依赖如何识别、保存和解析，以及 ROS 包名映射与项目资源引用如何转换。具体路径改写属于读写和导出程序，格式侧保证必要信息不丢失。

参考：[xacro 项目](https://github.com/ros/xacro)、[glTF 2.0 规范](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html)。

| 被采样的量 | 需要明确的内容 |
|---|---|
| 基座、障碍物或目标 frame 的位置 | 参考坐标系、名义位置和增量 |
| 朝向 | 随机旋转的表示、分布及组合方式 |

### 问题 1：机械臂配置的作用与内容

机械臂公共配置补充 URDF 的规划使用语义，包括相关参数及机器人在规划中的特定规则。URDF 已表达的结构、几何、关节轴和 mimic 关系优先引用，不重复维护。MoveIt 作为信息检查清单，不整体继承其配置体系。

| 信息 | 约定 |
|---|---|
| 模型引用与根 frame | 引用 URDF，明确场景安装 pose 对应的根 frame |
| 规划关节 | 指定独立规划关节及顺序 |
| TCP | 引用模型 frame；必要时补充所属 link 与固定变换 |
| 有效关节位置限制 | 采用模型限制，必要时明确更严格的规划限制 |
| 速度、加速度限制 | 纳入公共配置，作为可选信息 |
| 公共自碰撞规则 | 记录排除对及依据，表达机器人特定的碰撞检测行为 |
| 命名关节配置 | 包含 home、folded 等可复用配置；名称不自动指定用途或初始状态 |

参数按以下边界组织：场景保存机械臂实例、基座 pose、固定使用的非规划关节状态、环境与目标 frame；各臂任务保存初始规划关节状态、有序目标和完成条件。mimic 状态由模型推导，完整状态不能依赖未声明的零值。规划器、IK 插件和求解预算属于运行配置。

通用碰撞裕量属于碰撞检测配置，不列入机械臂公共配置；只有表达某个机器人或连杆特定处理时，才归入其碰撞配置。场景中的安装接触等对象对规则仍属于场景。

修正过程：此前暂不考虑速度、加速度限制；用户本次改为保留可选项。具体采用 SRDF、自定义配置或组合仍未决定。

### 问题 2：模型资源接口与处理原则

| 格式 | 特性与当前使用 |
|---|---|
| STL | 三角面几何，无标准父子节点或外部资源引用机制；多个不连通部分不构成层次。单位需由输入约定和缩放明确。当前用于碰撞检查和预览 |
| DAE／COLLADA | 可包含多个几何、父子节点及局部变换，也可引用外部纹理或其他 COLLADA 元素。当前 URDF 的 visual 已引用 DAE；检查的七个 UR 连杆 DAE 含并列节点，没有更深的节点嵌套 |

DAE 的外观层次不自动构成机器人关节；机器人运动学仍以 URDF 为准。若加载 DAE，应正确处理被引用的各几何和节点变换，不能只取第一个 mesh。

生成器接收机械臂公共配置、已展开 URDF 及其所需资源，接口约定如下：

- **URDF 中的资源路径必须为相对路径，以 URDF 所在目录为基准；不使用绝对路径或 `package://`。**
- 所需 mesh 及其依赖应完整、可解析；保留局部坐标、缩放和变换，不自动居中。
- xacro 展开、ROS 包依赖定位、路径改写和格式转换放在独立准备步骤中；具体工具不限定，生成器不负责这些步骤，也不要求 ROS 运行环境。
- 当前规划几何处理以 STL 为基础；可保留 DAE 外观资源，保留不等于已实现加载支持。其他格式按实际需求增加，不预建通用转换框架。

当前 `build_model.py` 已执行 xacro 展开和 mesh 相对路径改写；这只是准备工具的一种实现。源文件可独立维护，生成器只依赖最终交付物。

参考：[COLLADA 规范](https://www.khronos.org/files/collada_spec_1_5.pdf)、[COLLADA URI 引用](https://wikis.khronos.org/collada/Using_URIs_in_COLLADA)、[ROS 资源解析](https://github.com/ros/resource_retriever)。

## 追加：问题 3 的方案

日期：2026-09-21。先确定最小支持范围，用于形成可使用的输入实例；不追求一次覆盖所有分布。

### 抽象与最小支持范围

概率分布是统一的数学描述；具体属性决定样本的含义及应用规则。分布参数放在 generation 中，不为机械臂、障碍物和目标 frame 分别建立分布体系。

| 可采样属性 | 当前支持 | 样本含义 |
|---|---|---|
| 机械臂初始关节配置 | 独立均匀、单中心独立高斯 | 均匀分布给出实际关节位置范围；高斯围绕一个完整中心配置采样 |
| 障碍物位置扰动 | 各分量独立均匀 | 名义自身坐标系中的位置增量 |
| 障碍物朝向扰动 | 三个角度参数独立均匀 | 已约定的 alpha、beta、gamma；不是 SO(3) 均匀分布 |
| 目标 frame 位姿扰动 | 与障碍物位姿相同 | 改变相对父 frame 的名义 pose，父对象变化通过变换链传递 |
| 有关节障碍物的关节状态 | 独立均匀 | 指定独立关节的实际取值范围；当前桌面实例未使用 |

暂不考虑混合分布、旋转专用分布和完整协方差。名义状态不随样本累积变化，位姿继续采用 `p = p0 + R0 * delta_p`、`R = R0 * Rz(gamma) * Ry(beta) * Rx(alpha)`。

桌子等组合物体的内部几何相对于物体 frame 定义，改变整体相对 parent frame 的 pose 即可整体移动，无需另设共享扰动机制。

### 调研参考：哪些分布与这些属性有明确的对应关系

下表保留调研中的候选范围。“适用”表示数学与使用语义成立，不表示首版需要支持；当前范围仍以上述最小支持方案为准。

| 分布或构造 | 适用属性 | 适合表达的意图与限制 |
|---|---|---|
| 区间／盒内均匀分布 | 有限关节值、位置、位置增量、指定角度参数 | 覆盖有界参数范围；各维独立时得到矩形或高维盒 |
| 指定区域内均匀分布 | 平面或空间位置 | 在圆盘、球、可放置区域中均匀取点；必须说明按长度、面积还是体积均匀 |
| 高斯／多元高斯 | 关节增量、位置增量、局部旋转参数 | 围绕中心集中；完整协方差可以表达分量间相关性 |
| 截断高斯 | 有明确范围的上述变量 | 保留“中心附近更常见”，同时限制支持范围；不是越界后直接裁剪 |
| 有限离散分布 | 命名配置、有限候选姿态或中心 | 按权重选择一个完整候选 |
| 混合分布 | 多中心关节状态、多个摆放区域或姿态模式 | 先选择模式，再在该模式内采样 |
| 圆周分布 | 真正周期性的单轴角度 | 圆周均匀、wrapped normal、von Mises，可避免在 −π/π 处人为切断邻域 |
| 旋转专用分布 | 完整三维朝向 | SO(3) 均匀、局部旋转向量扰动，以及更专门的 Matrix Fisher／Bingham 等 |

参考：[Scenic 基础与离散分布](https://docs.scenic-lang.org/en/latest/reference/distributions.html)、[多元高斯](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.multivariate_normal.html)、[von Mises](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.vonmises.html)、[SO(3) 均匀采样](https://lavalle.pl/planning/node198.html)、[旋转概率建模](https://arxiv.org/html/2003.02180)。

### YAML 表达与省略规则

- 均匀分布：`type: uniform`、`independent: true`、`lower`、`upper`。上下界使用同一组分量名，且下界不大于上界。
- 高斯分布：`type: gaussian`、`independent: true`、`mean`、`stddev`。标准差非负，零表示固定在中心值。
- `mean` 二选一：`configuration: home` 引用对应机械臂公共配置中的命名配置，或 `joint_positions` 直接填写完整中心关节值。
- 位置分量使用 `x/y/z`，旋转参数使用 `alpha/beta/gamma`，关节值使用关节名；长度为米，角度为弧度。
- **不扰动就不写。** 未配置的对象、属性或扰动分量保持名义值；父 frame 的变化仍正常传递。此规则不适用于必需的初始关节状态，不能将缺失关节值默认补零。
- `null` 仅表示未决项，不表示固定、零扰动或默认分布。高斯不隐含截断或裁剪。

例如，仅扰动位置 x/y 和旋转 gamma：

```yaml
position:
  type: uniform
  independent: true
  lower: {x: -0.03, y: -0.03}
  upper: {x: 0.03, y: 0.03}
orientation:
  type: uniform
  independent: true
  lower: {gamma: -0.1}
  upper: {gamma: 0.1}
```

完整关节分布见 [generation.yaml](../../../examples/ur7e_table/inputs/tabletop/generation.yaml)：arm_a 使用 home 附近的均匀范围，arm_b 使用命名中心 home 和逐关节标准差。当前实例不同对象、两条臂分别独立采样，具体幅度、种子和数量是示例设置，不是通用默认值或可行性结论。

### 输入实例中的任务约定与未决项

当前序列使用 `sequence_generation.type: fixed`，`sequences` 保存各臂有序 frame 列表。每个 frame 在每个样本中只生成一次 pose，供所有引用共用；各臂同序号访问不要求同步。新增 above 目标是独立访问点，不隐含直线接近动作。

完成序列后返回实际初始关节配置，并停留在那里继续参与碰撞检测；已删除无必要的 `hold_after_return` 开关。`joint_tolerance_rad` 表示逐关节返回误差阈值，`dwell_time_s` 表示每次访问的停留时长，两者仍待确定。

越界、碰撞与不可达样本的处理尚未确定。分布及序列已填写不等于生成器已实现，也不代表随机样本或连续路径已验证；现有验证范围见[样例说明](../../../examples/ur7e_table/README.md#数值检查及其范围)。
