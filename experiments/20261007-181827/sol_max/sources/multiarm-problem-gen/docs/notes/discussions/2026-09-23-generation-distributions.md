## 从扰动的职责拆分谈起

用户提出三点：分布是独立且完整的概念；依据分布扰动场景的过程可以探索统一抽象；需要建立分布与作用对象的关联。本轮先明确“分布表示、作用关联”，具体应用过程等讨论生成新场景时再展开。

## 分布以多维联合分布表示

agent 曾提出标量或多维两种方向，用户明确选择多维联合分布，因为逐标量独立采样不能表达非独立关系。一个分布实例一次产生完整向量，各维是否独立属于分布性质，不由应用过程默认决定。同类型、不同参数对应不同实例；标量是一维特例。

局部方案：分布表示保存类型及其参数，明确输出维度，不包含场景对象或 frame 语义。首版仍采用独立均匀分布、独立高斯分布，作为联合分布的特例；这次没有扩大为实现一般相关分布。具体类与采样接口未定。

## 作用关联需要明确分量与含义

用户指出，只关联到对象还不够，需要知道作用于哪些分量，以及如何解释采样结果。讨论先提出“目标＋分量映射＋应用语义”，随后明确：应用语义由目标属性类别固定决定，不单独保存可选择的应用方式，也不意味着必须额外建立几种 class。

局部方案：

```text
作用关联
  分布引用
  目标对象及属性
  有序分量映射
```

例如二维分布输出 `[u, v]`，分量映射为 `[x, y]`，则 u 对应 x、v 对应 y。它们来自同一次联合采样，不能逐分量重新采样。目标属性应具有明确类别，不靠字段名称字符串猜测。

| 目标属性 | 采样值及固定应用语义 |
|---|---|
| frame 位置 | 名义自身坐标系中的位置增量：`p = p0 + R0 * delta_p` |
| frame 朝向 | 旋转扰动参数：`R = R0 * Rz(gamma) * Ry(beta) * Rx(alpha)` |
| 机器人初始规划关节状态 | 实际关节值，按关节映射直接构成配置 |

`p0、R0` 始终来自名义位姿；每次从名义状态采样，不累积扰动。位置增量的方向不受本次旋转扰动改变。目标 frame 的名义位姿相对于父 frame，父级变化沿变换链传递。

位姿扰动可只指定部分分量，未配置分量的增量为零；初始规划关节状态必须完整。高斯中心若引用 home，读取时解析为关节值；采样结果已是实际配置，不再加一次 home。

## 两个使用例子与边界

- 圆柱位置扰动：二维均匀分布关联 can_a 的 frame 位置，映射为 `[x, y]`；按名义自身坐标轴应用增量，z 增量为零。
- 机械臂初始状态：六维高斯分布关联 arm_b 的初始规划关节状态，按六个规划关节的明确顺序映射，直接得到配置。

当前不提供“叠加／替换”开关。以后若需要绝对位置采样等不同含义，应显式扩展目标类别或规则，不改变已有语义。采样器接口、随机数管理、生成顺序、重试及具体应用过程留待后续讨论。
