# 输出数据的有效性语义

日期：2026-09-21

状态：本轮讨论已确认的输出要求，尚未实现；不代表现有样例已经满足全部要求。

## 讨论与确认

用户希望生成的数据保证关节合法、状态无碰撞、目标有可用 IK 解。在讨论目标 IK 的碰撞检查范围时，用户明确：“保证单臂与环境无碰撞，也就是单独可达。”

这里的“单独可达”指存在合法、无碰撞的 IK 端点，不表示已验证从初始状态到目标的连续路径。目标 IK 检查忽略其他机械臂，不要求其他臂保持初始状态时该端点仍无臂间碰撞。

## 输出保证

- 联合初始状态：所有机械臂的初始关节值满足有效关节限位；各臂同时处于其初始状态时，不存在禁止的自碰撞、与环境碰撞及臂间碰撞。
- 每个“机械臂—访问目标”组合：至少存在一个满足有效关节限位和末端位姿容差的 IK 解。该解不存在禁止的单臂自碰撞及与环境碰撞；检查时忽略其他机械臂。
- 辅助 IK 解是满足目标要求的见证，不是规划器必须采用的固定关节终点；规划器可以选择其他满足目标要求的配置。

末端位姿容差沿用[当前设计](../../design.md)：位置欧氏距离不超过 0.001 m，朝向之间的最小旋转角不超过 1°。

## 保证边界与未决事项

不保证连续无碰撞路径存在、整条访问序列可完成或多臂协调任务有解。目标附近允许存在需要机械臂相互让路的情况，目标处的臂间冲突由后续协调规划处理。

本次只明确输出语义，不决定碰撞与 IK 后端、框架架构、无效样本的重试或筛选策略，也不决定每次访问保存一个还是多个辅助 IK 解。
