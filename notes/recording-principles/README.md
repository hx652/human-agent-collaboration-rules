## 社区调研

按用户要求，查阅社区仓库、讨论和文章中对类似记录问题的描述与分析，了解这些问题与模型特点或局限的关系，同时调研社区在记录和长期协作方面的成功经验。已有观察不作为完整问题清单，相关成因仍需核实。

两个独立上下文的 subagent 已分别完成首轮调研，均继承主会话的模型与推理强度。经主 agent 复核来源，整理为[记录问题与社区经验调研](research.md)，区分实测结果、第一方实践经验、个案反馈与建议。

按用户补充要求，沿用两位 subagent，分别查跨 Session 延续与恢复、多个 agent 的协调与整合，关注可读记录之外的手段及实际效果。结果见[跨 Session 和多个 agent 协作的补充调研](collaboration-research.md)，包含运行状态、环境恢复、任务协调、通信、隔离和验证等机制及其证据边界。
