# 记录原则

## 适用场景

以下场景仅作示例，不限定记录的适用范围：

- **理解与探索**：想法讨论、知识学习、资料调研、复盘与经验总结。
- **设计与决策**：方案设计、比较、选择与取舍。
- **实践与验证**：工作实施、问题排查、实验与测试。

具体活动可以跨类，不为每类记录规定固定结构。

## 内容取舍

以内容对理解和脉络的作用作为取舍依据。

保留理解问题及其演变所需的内容，使读者能够了解初始问题、想法与讨论如何发展、选择及结果如何形成。影响理解的依据、分歧、错误、失败尝试和转折应予保留。

关键内容表达充分，重复且不增加信息的表达可以合并，无关的操作细节可以省略。避免让大量次要细节淹没要点。

已有可靠资料按需引用或提供定位，减少重复维护无关、易过时的状态。若某个当时状态影响了判断，应保留相关事实及其影响。

## 表达与原意

表达清晰、简洁、易于阅读和理解，结构和详略随内容安排。

整理、合并或压缩时保持原意，不补出未发生的过程。明确区分用户与 agent 的表述，保留必要的不确定性，不将猜想、候选或未决事项写成已确认结论。

## 文件组织

记录文件应按内容的主题、用途和相互关系组织，结合仓库现有结构选择合适的存放位置。目录和文件命名应清楚反映内容，相关记录按需建立引用，方便检索和查看。

## 主动建议记录

agent 应主动留意当前的讨论和工作进展，在已有内容足以形成一份有意义的记录时，主动建议记录。已有明确记录要求时，按要求执行。

## 整理结果的原意审查

本项审查只核查整理结果是否忠实表达原始材料的意思，可作为完整审查的一部分，不代表其他方面已被审查。

- **整理用户与 agent 的交流**：默认启用本项审查，并向用户说明。
- **完全由 agent 生成、并非整理双方交流的材料**：不默认执行本项审查，仅向用户提出审查建议。

原始材料的获取与交接应遵循[信息获取与隔离约定](RULES.md#信息获取与隔离)。审查所用的原始材料，优先取自相关的本地 session 记录文件，按需提取原始对话并保留出处。来源不可用或不完整时，说明限制并补充其他可核实材料。摘要或整理稿不能替代可获取的原文。

启用本项审查时，使用 subagent 独立比对根据原始材料和整理结果分别形成的理解，检查影响理解的遗漏、含义变化和无依据的补充。

可由两个独立上下文分别只读原始材料和整理稿，先保存各自理解，再由独立审查者比对并回查依据。具体配置根据材料规模和重要性决定，不要求每次采用相同流程。

审查意见应回到材料核实，并说明差异及其影响。合理压缩产生的详略差异可以接受；原始材料阅读者的理解也需要核验。
