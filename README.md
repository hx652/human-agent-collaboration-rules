# 人与 agent 协作规则

本仓库用于整理、讨论和持续完善人与 agent 的长期协作规则，并保留规则的原始依据。

通用规则见[通用协作原则](RULES.md)，专题内容见[Git 使用约定](GIT.md)、[代码相关原则](CODE.md)和[Serena 使用指南](SERENA.md)。

作为规则依据，已完成 47 份原始材料的筛选与分类：

- [原始协作要求](collection/REQUIREMENTS.md)：14 份约定、目标与偏好，以及散见于产物中的明确诉求。
- [体现要求的产物](collection/ARTIFACTS.md)：33 份讨论、方案、交接和复盘，包含执行中的偏差与纠正。

先看要求，需要具体情境时再查产物。保留原文的确认状态，候选建议不直接当作规则。

原文集中在 `sources/`，内容和来源相对路径保持不变。[筛选记录](collection/SELECTION.md)、[来源清单](collection/manifest.json)和[六组对比试验](experiments/20261007-181827/REPORT.md)仅在需要追溯时查阅。

方案讨论见 [讨论记录索引](notes/README.md)。
